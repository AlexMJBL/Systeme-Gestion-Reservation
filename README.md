# Système de Gestion et Réservation (Hôtels & Voitures)

Application web développée en **ASP.NET Core Razor Pages** permettant la gestion conjointe des réservations de chambres d'hôtel et de véhicules de location pour les particuliers et entreprises.

## Fonctionnalités

- 🏨 **Gestion Hôtelière** : Consultation des chambres disponibles, filtrage par type et enregistrement des séjours.
- 🚗 **Location de Véhicules** : Sélection de flotte de véhicules, suivi de la disponibilité et calendrier de réservation.
- 📅 **Gestion des Conflits** : Contrôle de disponibilité en temps réel pour empêcher les doubles réservations.
- 💻 **Interface Responsive** : Design ergonomique propulsé par Bootstrap pour une navigation fluide sur mobile et bureau.

## Lancement Local

```bash
dotnet restore
dotnet build
dotnet run
```
Accédez ensuite à l'application via `https://localhost:5001`.
